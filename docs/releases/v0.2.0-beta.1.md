# v0.2.0-beta.1 developer beta

This release is for developers and hardware compatibility testing. It is not a
production authentication release.

## What works

- CPU-only YuNet detection and SFace embeddings through OpenCV
- daemon-owned five-pose enrollment with held-out validation
- encrypted, atomic profile commit using the development key flow
- Qt6 enrollment GUI with the lightweight dot-matrix scanner
- Forget Me deletion of the profile, manifest, and local key
- on-demand camera lease and privacy-safe latency diagnostics
- minimal PAM IPC module that remains fail-closed
- Ubuntu 24.04 and 26.04 x86_64 build/package coverage
- guarded, read-only-by-default Hyprlock PAM planning

## What is deliberately disabled

- thresholded biometric authentication success
- automatic Hyprlock unlock or lock-surface rendering
- liveness or presentation-attack protection
- production key storage
- automatic PAM edits
- display-manager or pre-login authentication

Password or PIN fallback is mandatory. `FACE_UNLOCK_DEV_ALLOW=1` is not real
biometric authentication and must never be used as a daily unlock mechanism.

## Install and inspect

Download the `.deb` matching the host Ubuntu release. Packages are tied to the
OpenCV ABI of the runner that built them.

    dpkg-deb -I ./face-unlock-linux_*_amd64.deb
    dpkg-deb -c ./face-unlock-linux_*_amd64.deb | less
    sudo apt install ./face-unlock-linux_*_amd64.deb

The package installs the daemon, enrollment GUI, desktop launcher, helper
tools, documentation, and PAM module. Installation does not start a service,
download model weights, enroll a face, or change PAM configuration.

## Developer test flow

Clone this tag so the pinned model downloader and local documentation are easy
to inspect:

    git clone --branch v0.2.0-beta.1 \
      https://github.com/justneeraj12/face-unlock-linux.git
    cd face-unlock-linux
    ./scripts/download-cpu-models.sh

Start the installed daemon with the local verified models:

    face-unlockd \
      --camera 0 \
      --detector yunet \
      --detector-model "$PWD/models/face_detection_yunet.onnx" \
      --recognizer-model "$PWD/models/face_recognition_sface_2021dec.onnx" \
      --daemon

In another terminal, launch:

    face-unlock-enroll

The app can build and save an encrypted profile. An `auth` request must still
fail closed because the acceptance matcher is disabled.

## Hardware reports

Please use the hardware compatibility issue form and share only numeric timing,
OS, CPU, camera model/driver, and reproducible errors. Never upload faces,
frames, embeddings, templates, or keys.

Useful commands:

    ./scripts/benchmark-camera-lease.sh --camera 0
    ./scripts/benchmark-native-verification.sh --camera 0 --iterations 20
    python3 python/benchmark_cpu_models.py --iterations 100

## Model sources and redistribution

The release package does not bundle model weights. The downloader retrieves
checksum-pinned YuNet and SFace files from OpenCV Zoo. YuNet is documented as
MIT; the SFace directory is documented as Apache-2.0. A complete model
provenance and redistribution review remains required before bundling weights.

## Upgrade, uninstall, and rollback

Remove the package with:

    sudo apt remove face-unlock-linux

This does not delete user biometric files. Use the GUI's Forget Me action first
if the encrypted profile, manifest, and development key should also be removed.

No PAM service is changed by installation. If a developer previously opted
into a guarded test integration, use the exact backup and rollback command
printed by that helper before removing the package.
