# v0.2.0-dev-auth-sudo Release Notes

v0.2.0-dev-auth-sudo is planned as a development-only sudo integration hardening release.

It is not production biometric authentication.

## Planned focus

- safer guarded sudo apply flow
- clearer rollback behavior
- root peer auth policy hardening
- sudo troubleshooting improvements
- fake PAM and sudo dry-run test improvements
- better developer automation around sudo testing

## Planned additions

- improved sudo apply preflight checks
- optional daemon/service root-auth peer configuration docs
- stronger sudo rollback validation
- sudo test matrix
- clearer dev-auth warnings
- updated local verification for sudo development

## Security goals

- sudo auth must remain fail-closed by default
- password fallback must remain available
- root-owned auth peers must remain explicitly opt-in
- rollback must be documented and tested
- development auth must never be presented as real biometric auth

## Non-goals

- real face recognition
- real biometric matching
- lock-screen integration
- greeter integration
- production sudo deployment
