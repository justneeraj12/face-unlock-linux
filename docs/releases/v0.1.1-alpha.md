# v0.1.1-alpha Release Notes

v0.1.1-alpha is a post-alpha infrastructure update.

It is still not real biometric authentication.

## Highlights

- GUI scaffold improvements
- Enrollment manifest scaffold improvements
- Model evaluation scaffolds
- Dependency audit tooling
- Release artifact workflow
- Development key management scaffold
- Development-key placeholder template flow
- Daemon template_status operation
- Key-aware auth failure reasons
- Additional integration tests

## Added

- Development key tool.
- Template tool support for --use-dev-key.
- Template decrypt verification without printing plaintext.
- Daemon key/decryptability metadata.
- template_status daemon socket operation.
- Auth reason integration test.
- Daemon metadata integration test.
- Key/template integration test.
- Model evaluation metrics format and validator.
- GitHub release artifact workflow.
- Script inventory checker.
- Dependency audit script.
- GUI camera preview placeholder.
- GUI quality checklist scaffold.
- GUI pose slots scaffold.
- GUI brightness assist placeholder.
- GUI Forget Me scaffold.

## Changed

- Root sudo auth peer support is now explicitly gated by FACE_UNLOCK_ALLOW_ROOT_AUTH=1.
- Auth failures now distinguish template/key/decryptability states.
- README was refactored into a cleaner front page.
- CI now validates scripts, manifests, metrics, and dependencies.

## Security

- No real biometric authentication yet.
- Auth remains fail-closed by default.
- Development auth remains explicit and non-production.
- Development key file is a scaffold only.
- Key material and plaintext are not printed.
- PAM module remains minimal and audited.
- sudo integration remains guarded and rollback-focused.

## Not included

- Real face detection.
- Real face alignment.
- Real embedding matching.
- Real biometric enrollment.
- Production key management.
- Production sudo integration.
- Lock-screen integration.
- Greeter integration.
